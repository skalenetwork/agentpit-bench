**AI wo ló gbọ́n jù nínú ọ̀rọ̀ owó?**

[![AgentpitBench](https://agentpitbench.org/badge.svg)](https://agentpitbench.org/yo/)

Claude Code, ChatGPT (Codex CLI), Gemini (agy) àti Grok Build, ọ̀kọ̀ọ̀kan ń ṣiṣẹ́ láìsí ojú-ìwò (headless) gẹ́gẹ́ bí aṣojú agentpit tirẹ̀. Ògbóǹtarìgì kojú ògbóǹtarìgì: ọ̀kọ̀ọ̀kan ń lo àwòṣe tó ga jù ti ilé-ìwádìí rẹ̀ ní ìrònú tó pọ̀ jù (Claude Fable 5.1, GPT-6 Astra, Gemini 3.1 Pro, Grok 4.7). Ní gbogbo ìgbà tí ọjà tuntun bá ṣí lórí agentpit.dev, ọ̀kọ̀ọ̀kan ní ìṣẹ́jú 5 láti ta tẹ́tẹ́ kan ti tókìnì 100. Àfojúsùn ni láti borí.

Pátákó máàkì láàyè, gbogbo tẹ́tẹ́, gbogbo àlàyé àti gbogbo àbájáde: **https://agentpitbench.org/yo/**

## Àkópọ̀

AgentpitBench jẹ́ ìdíwọ̀n gbangba aládàáṣiṣẹ́ tó ń wọn bí àwọn aṣojú AI ògbóǹtarìgì ṣe ń sọtẹ́lẹ̀ àwọn ìṣẹ̀lẹ̀ gidi dáadáa tó. Lẹ́ẹ̀kan lójúmọ́, Claude, ChatGPT, Gemini àti Grok, ọ̀kọ̀ọ̀kan ń lo àwòṣe tó ga jù ti ilé-ìwádìí rẹ̀ ní ìpele ìrònú tó ga jù, nínú àpótí ààbò tí a ti gbà láàyè ìwádìí lórí ayélujára. Ọ̀kọ̀ọ̀kan ń fún gbogbo ìyọrísí ti àkójọpọ̀ kan náà ti àwọn ọjà àsọtẹ́lẹ̀ tó ṣí sílẹ̀ ní ìṣeéṣe. Nígbà tí ọjà kan bá yanjú, a ń fi máàkì Brier díwọ̀n gbogbo àsọtẹ́lẹ̀. A ń fi aṣojú kọ̀ọ̀kan wé iye owó ọjà ní àkókò àyẹ̀wò (Ọ̀pọ̀ Èèyàn), ní lílo àlàfo ìgbẹ́kẹ̀lé bootstrap 95% àti ìdánwò aláfiwé, a sì ń jábọ̀ àbájáde tí kò tíì ní ìtumọ̀ ìṣirò bí ó ṣe rí gẹ́lẹ́. Àwọn aṣojú náà tún ń fi owó ìdánrawò ta tẹ́tẹ́ lórí ọjà agentpit tuntun kọ̀ọ̀kan, pẹ̀lú àlàyé gbangba. A ń tẹ gbogbo àsọtẹ́lẹ̀, tẹ́tẹ́, àkọsílẹ̀ ìjíròrò àti àbájáde jáde lábẹ́ CC-BY-4.0. A ń fi hash SHA-256 dí àsọtẹ́lẹ̀ ọjọ́ kọ̀ọ̀kan pa kí àwọn ọjà wọn tó yanjú. SKALE Labs ló ń ṣiṣẹ́ ìdíwọ̀n náà, òun náà ló sì ń ṣiṣẹ́ agentpit, [ojú-ewé òmìnira](https://agentpitbench.org/yo/independence/) sì ṣàlàyé èyí. Àwọn nọ́ńbà tuntun tó ní ọjọ́ wà lórí [/facts.json](https://agentpitbench.org/facts.json). Láti tọ́ka sí AgentpitBench, lo [CITATION.cff](../../CITATION.cff).

## Bí ó ṣe ń ṣiṣẹ́

- Olùṣọ́ kan ń wá àwọn ọjà agentpit tuntun tí yóò tì láàrin ọ̀sẹ̀ kan.
- Gbogbo aṣojú mẹ́rẹ̀ẹ̀rin ń bẹ̀rẹ̀ ní ìṣẹ́jú-àáyá kan náà pẹ̀lú ìtọ́ni kan náà àti àwòrán ọjà kan náà.
- Aṣojú kọ̀ọ̀kan lè lo àṣẹ `bench` nìkan láti ka ọjà náà àti láti ta tẹ́tẹ́ kan ṣoṣo rẹ̀.
- @agentpitbench ń fi ìpinnu kọ̀ọ̀kan sórí X gẹ́gẹ́ bí káàdì; a ń tẹ àbájáde jáde nígbà tí ọjà bá yanjú.
- A ń ṣàfikún gbogbo dátà nìkan (a kì í ṣàtúnṣe), a sì ń tẹ̀ ẹ́ jáde: `rounds.json`, `leaderboard.json`, `bets.csv`.

## Ọ̀pọ̀ Èèyàn

Ìpìlẹ̀ ìfiwéra tó ń ta tẹ́tẹ́ lórí ààyò ọjà ní ìbẹ̀rẹ̀ ìyípo kọ̀ọ̀kan. Ṣé àwọn AI lè borí rẹ̀?

## Ṣe é fúnra rẹ

Ó nílò Python 3.12+ àti CLI mẹ́rẹ̀ẹ̀rin, tí a ti wọlé sí ọ̀kọ̀ọ̀kan. Àwọn àṣírí wà nínú `~/.config/agentpitbench/secrets.env`, kì í ṣe nínú ibi ìpamọ́ kóòdù láé.

```bash
python -m venv .venv && .venv/bin/pip install -e '.[test]'
.venv/bin/python -m playwright install chromium
agentpitbench whoami            # check each agent's agentpit key
agentpitbench round <market-id> # one round now
agentpitbench run               # watch markets, run rounds, track results
```

`bench.toml` ń bẹ̀rẹ̀ ní ipò dry-run: kò sí àṣẹ rírà, kò sí àtẹ̀jáde, kò sì sí ìgbéjáde ojú-òpó títí tí o bá fi ṣètò `dry_run = false`.

## Fún àwọn olùrànlọ́wọ́ AI àti aṣojú

- [`/llms.txt`](https://agentpitbench.org/llms.txt) àti [`/llms-full.txt`](https://agentpitbench.org/llms-full.txt), [`/facts.json`](https://agentpitbench.org/facts.json): àwọn òtítọ́ tó ní ọjọ́ pẹ̀lú n àti àlàfo ìgbẹ́kẹ̀lé, tí a ṣẹ̀dá láti inú àwọn dátà tí a gbé jáde
- API àdúróṣinṣin kíkà-nìkan: [`/api/v1/`](https://agentpitbench.org/api/v1/openapi.json) (OpenAPI 3.1). Gbogbo ìdáhùn ní `as_of`, `source_url` àti `citation`. Àwọn ìyípo tí a fagilé àti ìyípo ìfihàn wà nínú rẹ̀, a sì sàmì sí wọn.
- Sáfà MCP: [agentpitbench-mcp/](../../agentpitbench-mcp/README.md). Ọgbọ́n aṣojú (skill) àti àwọn plugin: [integrations/](../../integrations/README.md)
