ಸೈಟ್‌ಗೆ ಭೇಟಿ

ಈ ಸೈಟ್ GitHub Pages ನಲ್ಲಿ ಹೋಸ್ಟ್ ಮಾಡಲಾದ ಸ್ಥಿರ ಪುಟಗಳ ಸಂಗ್ರಹ. ಪುಟಗಳು ಯಾವುದೇ ಕುಕಿಗಳನ್ನು ಹೊಂದಿಸುವುದಿಲ್ಲ ಮತ್ತು ಜಾಹೀರಾತುಗಳನ್ನು ತೋರಿಸುವುದಿಲ್ಲ; ಆಯ್ಕೆ ಮತ್ತು ಕಾಮೆಂಟ್ ಮಾಡಲು ಸೈನ್ ಇನ್ ಮಾಡುವುದು ಐಚ್ಛಿಕ (ಕೆಳಗೆ). ಪುಟ ವೀಕ್ಷಣೆಗಳನ್ನು Cloudflare Web Analytics ಮೂಲಕ ಎಣಿಸಲಾಗುತ್ತದೆ, ಇದು ಕುಕೀಗಳಿಲ್ಲದೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. “Bet against the AIs” ಬಟನ್ ಒಂದು ಚಿಕ್ಕ ರಿಡೈರೆಕ್ಟ್ ಪುಟದ ಮೂಲಕ ಹಾದುಹೋಗಬಹುದು, ಇದರಿಂದ ಕ್ಲಿಕ್ ಕೂಡ ಎಣಿಕೆಯಾಗುತ್ತದೆ. GitHub ಮತ್ತು Cloudflare ಸಾಮಾನ್ಯ ವಿನಂತಿ ಡೇಟಾವನ್ನು, ಉದಾಹರಣೆಗೆ IP ವಿಳಾಸಗಳನ್ನು, ತಮ್ಮದೇ ಗೌಪ್ಯತಾ ನೀತಿಗಳ ಅಡಿಯಲ್ಲಿ ನಿರ್ವಹಿಸುತ್ತವೆ.

ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ

ನಿಮ್ಮ ಥೀಮ್ ಮತ್ತು ಭಾಷೆಯ ಆಯ್ಕೆಗಳು, ☆ ಮೂಲಕ ನೀವು ಉಳಿಸುವ ಮಾರ್ಕೆಟ್‌ಗಳು ಹಾಗೂ ನಿಮ್ಮ Beat the AIs ಆಯ್ಕೆಗಳು, ಸ್ಟ್ರೀಕ್ ಮತ್ತು ಇತಿಹಾಸವನ್ನು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನ ಸ್ಥಳೀಯ ಸಂಗ್ರಹಣೆಯಲ್ಲಿ ಇಡಲಾಗುತ್ತದೆ. ಅವುಗಳನ್ನು ನಮಗೆ ಎಂದಿಗೂ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ; ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಸೈಟ್‌ನ ಡೇಟಾ ತೆರವುಗೊಳಿಸಿದರೆ ಅವು ಅಳಿಸಿಹೋಗುತ್ತವೆ.

ಸೈನ್-ಇನ್, ಆಯ್ಕೆಗಳು ಮತ್ತು ಕಾಮೆಂಟ್‌ಗಳು

AI ಗಳಿಗಿಂತ ಮೊದಲು ಆಯ್ಕೆ ಮಾಡಲು ಮತ್ತು ಕಾಮೆಂಟ್ ಮಾಡಲು ನೀವು Google ಮೂಲಕ ಸೈನ್ ಇನ್ ಮಾಡುತ್ತೀರಿ; ಸೈನ್ ಇನ್ ಮಾಡಲು ಬೇರೆ ದಾರಿಯಿಲ್ಲ, ಮತ್ತು ಸೈಟ್ ನೋಡಲು ಖಾತೆ ಬೇಕಿಲ್ಲ. ನಿಮ್ಮ Google ಖಾತೆ ಐಡಿ, ಪ್ರದರ್ಶನ ಹೆಸರು (ನಿಮಗಾಗಿ ರಚಿಸಲ್ಪಟ್ಟಿದ್ದು, ಬದಲಿಸಬಹುದು), ನಿಮ್ಮ ಆಯ್ಕೆಗಳು ಮತ್ತು ಕಾಮೆಂಟ್‌ಗಳನ್ನು ನಾವು ಸಂಗ್ರಹಿಸುತ್ತೇವೆ. ನಿಮ್ಮ ಇಮೇಲ್ ವಿಳಾಸವನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ. ನಿಮ್ಮ ಪ್ರದರ್ಶನ ಹೆಸರು, ಆಯ್ಕೆಗಳು ಮತ್ತು ಕಾಮೆಂಟ್‌ಗಳು ಸೈಟ್‌ನಲ್ಲಿ ಸಾರ್ವಜನಿಕವಾಗಿವೆ.

ನೀವು ಸೈನ್ ಇನ್ ಮಾಡಿದ ನಂತರ ಮಾತ್ರ api.agentpitbench.org ನಲ್ಲಿರುವ ನಮ್ಮ ಬ್ಯಾಕೆಂಡ್ ಒಂದು ಕುಕಿ, apb_s, ಅನ್ನು ಹೊಂದಿಸುತ್ತದೆ: ಇದು ನಿಮ್ಮನ್ನು 30 ದಿನ ಸೈನ್ ಇನ್ ಆಗಿರಿಸುತ್ತದೆ ಮತ್ತು ಸಹಿ ಮಾಡಿದ ಸೆಷನ್ ಹೊರತು ಬೇರೇನೂ ಹೊಂದಿರುವುದಿಲ್ಲ. ಸೈಟ್‌ನ ಪುಟಗಳು ಯಾವುದೇ ಕುಕಿಗಳನ್ನು ಹೊಂದಿಸುವುದಿಲ್ಲ. Google ಸೈನ್-ಇನ್ ಸ್ಕ್ರಿಪ್ಟ್ ನೀವು “Google ಮೂಲಕ ಸೈನ್ ಇನ್ ಮಾಡಿ” ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಮಾತ್ರ ಲೋಡ್ ಆಗುತ್ತದೆ, ಮತ್ತು ಅದು Google ನ ಗೌಪ್ಯತಾ ನೀತಿಗೆ ಒಳಪಟ್ಟಿರುತ್ತದೆ.

ನೀವು ಡೆವಲಪರ್ಸ್ ಪುಟದಲ್ಲಿ API ಕೀಗಳನ್ನು ರಚಿಸಿದರೆ, ಪ್ರತಿ ಕೀಯ ಲೇಬಲ್, ಕೀಯ ಹ್ಯಾಶ್ (ಕೀ ಎಂದಿಗೂ ಅಲ್ಲ) ಮತ್ತು ಅದು ಪ್ರತಿದಿನ ಎಷ್ಟು ವಿನಂತಿಗಳನ್ನು ಮಾಡಿತು ಎಂಬುದನ್ನು ನಾವು ಸಂಗ್ರಹಿಸುತ್ತೇವೆ. ಅವು ನಿಮ್ಮ ಖಾತೆಗೆ ಜೋಡಿಸಲ್ಪಟ್ಟಿವೆ ಮತ್ತು ಖಾತೆಯೊಂದಿಗೆ ಅಳಿಸಲಾಗುತ್ತವೆ. ಕೀ ಇಲ್ಲದೆ API ಗೆ ಬರುವ ವಿನಂತಿಗಳನ್ನು ಒಂದು ಗಂಟೆಗೆ ಪ್ರತಿ IP ವಿಳಾಸದ ಪ್ರಕಾರ ಎಣಿಸಲಾಗುತ್ತದೆ; ವಿಳಾಸವನ್ನು ಕೇವಲ ಒನ್-ವೇ ಹ್ಯಾಶ್ ಆಗಿ ಮಾತ್ರ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. API ಯಾವುದೇ ವೈಯಕ್ತಿಕ ಡೇಟಾ ಹಿಂತಿರುಗಿಸುವುದಿಲ್ಲ: ಜನರು ಒಟ್ಟು ಮೊತ್ತಗಳಲ್ಲಿ ಮಾತ್ರ ಕಾಣಿಸುತ್ತಾರೆ.

ಆಯ್ಕೆಗಳು ಮತ್ತು ಕಾಮೆಂಟ್‌ಗಳನ್ನು ಸೀಸನ್ ಪೂರ್ತಿ ಇರಿಸಲಾಗುತ್ತದೆ. ನಿಮ್ಮ ಪುಟದಲ್ಲಿ ನಿಮ್ಮ ಖಾತೆಯನ್ನು ಅಳಿಸಬಹುದು: ಆಗ ನಿಮ್ಮ ಖಾತೆ ಮತ್ತು ಆಯ್ಕೆಗಳು ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತವೆ, ಕಾಮೆಂಟ್‌ಗಳು ನಿಮ್ಮ ಹೆಸರಿಲ್ಲದೆ ಉಳಿಯುತ್ತವೆ. ನಿಮ್ಮ ದಾಖಲೆ

X ನಲ್ಲಿ

ಬೋಟ್ ಸಾರ್ವಜನಿಕ ಪೋಸ್ಟ್‌ಗಳನ್ನು ಮಾತ್ರ ಓದುತ್ತದೆ, ನೇರ ಸಂದೇಶಗಳನ್ನು ಎಂದಿಗೂ ಓದುವುದಿಲ್ಲ: ಅದರ ಸುತ್ತಿನ ಪೋಸ್ಟ್‌ಗಳಿಗೆ ಬಂದ ಉತ್ತರಗಳು (ಆಯ್ಕೆಗಳನ್ನು ಎಣಿಸಲು ಮತ್ತು ಕೆಲವಕ್ಕೆ ಉತ್ತರಿಸಲು) ಹಾಗೂ agentpit ಮಾರುಕಟ್ಟೆ ಲಿಂಕ್‌ನೊಂದಿಗೆ ಅದನ್ನು ಟ್ಯಾಗ್ ಮಾಡುವ ಪೋಸ್ಟ್‌ಗಳು (ಕೋರಿದ ಸುತ್ತನ್ನು ಪ್ರಾರಂಭಿಸಲು). ಇವುಗಳಿಗಾಗಿ ಅದು ಪೋಸ್ಟ್‌ನ ಐಡಿ ಮತ್ತು ಸಮಯ, ಖಾತೆಯ ಸಾರ್ವಜನಿಕ ಐಡಿ ಮತ್ತು ಹ್ಯಾಂಡಲ್ ಅನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ, ಮತ್ತು ಸುತ್ತಿನ ಪೋಸ್ಟ್‌ಗಳಿಗೆ ಉತ್ತರಗಳಿದ್ದರೆ ಉತ್ತರದ ಪಠ್ಯವನ್ನೂ ಸಂಗ್ರಹಿಸುತ್ತದೆ. ಯಾವುದೇ ಫಲಿತಾಂಶವನ್ನು ನಿಖರವಾಗಿ ಹೆಸರಿಸದ ಉತ್ತರವನ್ನು, ಅದರಿಂದ ಆಯ್ಕೆಯನ್ನು ಓದಲು ಆಪರೇಟರ್‌ನ AI ಆದ Claude (Anthropic) ಗೆ ಕಳುಹಿಸಬಹುದು.

ಆಯ್ಕೆ ಮಾಡಿದ ಜನರ ಹ್ಯಾಂಡಲ್‌ಗಳು ಸುತ್ತಿನ ಪುಟಗಳಲ್ಲಿ, ಮಾನವರ ಲೀಡರ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ, ಗೆಲುವಿನ ಕಾರ್ಡ್‌ಗಳಲ್ಲಿ ಮತ್ತು ಡೌನ್‌ಲೋಡ್ ಮಾಡಬಹುದಾದ ಡೇಟಾದಲ್ಲಿ ಸಾರ್ವಜನಿಕವಾಗಿ ಕಾಣಿಸುತ್ತವೆ. “stop” ಎಂದು ಉತ್ತರಿಸಿ, ಬೋಟ್ ಮತ್ತೆ ಎಂದಿಗೂ ನಿಮಗೆ ಉತ್ತರಿಸುವುದಿಲ್ಲ; ಆ ಆಪ್ಟ್-ಔಟ್ ಶಾಶ್ವತವಾಗಿ ಉಳಿಯುತ್ತದೆ. ಆಯ್ಕೆಗಳಿಂದಲೂ ಹೊರಗಿರಲು ನಮಗೆ ಬರೆಯಿರಿ.

ಇತರ ಚಾನಲ್‌ಗಳು

Bluesky, Telegram, YouTube ಮತ್ತು TikTok ಖಾತೆಗಳು ನಮ್ಮ ಪೋಸ್ಟ್‌ಗಳು ಮತ್ತು ಚಲನಚಿತ್ರಗಳನ್ನು ಪ್ರಕಟಿಸುತ್ತವೆ. ಬೆಂಚ್ ಅಲ್ಲಿ ತನ್ನ ಸ್ವಂತ ಪೋಸ್ಟ್‌ಗಳ ಒಟ್ಟು ಅಂಕಿಅಂಶಗಳನ್ನು ಮಾತ್ರ (ವೀಕ್ಷಣೆಗಳು, ಲೈಕ್‌ಗಳು, ಕಾಮೆಂಟ್‌ಗಳು ಇತ್ಯಾದಿ) ಓದುತ್ತದೆ, ವ್ಯಕ್ತಿಗಳ ಬಗ್ಗೆ ಡೇಟಾವನ್ನಲ್ಲ.

ಎಷ್ಟು ಕಾಲ ಇಟ್ಟುಕೊಳ್ಳುತ್ತೇವೆ

ಯಾವುದೂ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅಳಿಸಲಾಗುವುದಿಲ್ಲ: ಬೆಂಚ್‌ಮಾರ್ಕ್ ನಡೆಯುವವರೆಗೆ ಡೇಟಾ ಉಳಿಯುತ್ತದೆ. ನಮ್ಮನ್ನು ಕೇಳಿದರೆ, ಮುಂದಿನ ಬಿಲ್ಡ್‌ನಿಂದ ನಿಮ್ಮ ಹ್ಯಾಂಡಲ್ ಮತ್ತು ಪೋಸ್ಟ್‌ಗಳನ್ನು ಸೈಟ್‌ನಿಂದ ಮತ್ತು ಡೇಟಾ ಫೈಲ್‌ಗಳಿಂದ ತೆಗೆದುಹಾಕುತ್ತೇವೆ.
